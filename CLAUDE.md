# CLAUDE.md - Radio Crunchy

## Project Overview
Radio Crunchy website - placeholder for now, full site TBD.

## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Package Manager:** pnpm

## Development
```bash
pnpm install
pnpm dev
```

## Deploy
- **Platform:** Vercel
- **Auto-deploy:** Push to `main` triggers production deploy
- **Preview:** PRs get preview deployments

## Workflow
- Create feature branches for changes
- Open PRs for review
- Merge to `main` for production
